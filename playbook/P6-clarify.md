# Phase 6 — Clarification — `/brd-p6-clarify`

**Follow:** `P0-phase-rules.md` · **Closes with:** APPROVED (only when neither side has open questions, or the user accepts the rest as open) · **Output:** `brd/P6-clarify.md`

## Purpose
Close the gaps with people. This phase runs as many rounds as needed.

## Each round
1. Take open gaps (HIGH first), grouped by topic so one answer can close several.
2. For each, check the evidence once more (memory, a read-only data check if a connection exists, Genie and DevOps if in use) so people are only asked what the evidence cannot answer.
3. Ask (at most 8 per round): context with sources, the question, options, the agent's suggested answer (marked as a suggestion), and who probably knows (from `PROJECT.md` people).
4. Record answers as Confirmed with the name of the person who gave them (`people-and-confirmations.md`); update every earlier phase statement it affects **in this phase's output** (earlier approved phase files are not edited; the change is listed under "Changes to earlier phases" so phase 8 uses the latest answer).
5. Answers that point to future state are tagged Future state and listed under "Corrections the memory should receive".

## Exit
The phase ends when the agent states "I have no further questions" and the user has no more clarifications, or the user decides to leave the remaining items open; those go to phase 7.

## Review page
Questions this round (`### Q-…`), decisions recorded so far (with who confirmed each), changes to earlier phases, gaps remaining.
